# Oromia STEM Suite

A bilingual (English / Afaan Oromoo) browser-based virtual physics laboratory for Ethiopian secondary-school learners.

## Included
- 2D projectile motion with speed, angle, launch height, and gravity controls
- Refraction ray tracing using Snell's law and total internal reflection conditions
- Thin-lens bench using the Gaussian lens equation and magnification
- Five original EUEE-style practice questions with feedback and score tracking
- Bilingual interface, core notes, responsive phone-friendly layout
- No external libraries, build step, API, or backend

## Publish on GitHub Pages using a phone
1. Open your GitHub repository in the browser.
2. Open `index.html` (or create it if the repository is empty).
3. Tap the pencil / Edit button, replace the file contents with the provided `index.html`, and commit the changes. If pasting a large file is inconvenient, upload `index.html` from your phone instead.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. Open the published URL shown in Settings → Pages.

## Notes
- The simulations are idealized teaching models: projectile motion ignores air resistance; the thin lens is ideal; the refraction boundary is flat.
- The EUEE questions are newly written practice questions, not reproductions of an official past paper.
- GitHub Pages publishes static files only. No backend is required for these features.
