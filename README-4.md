# Oromia STEM Suite

A bilingual (English/Afaan Oromoo) virtual physics laboratory for secondary-school learners. Built with plain HTML, CSS, and JavaScript, with no external libraries or backend.

## Files
- `index.html` — page structure and content
- `styles.css` — all visual styles and responsive layout
- `script.js` — interactive simulations, language switching, and multiple-choice quiz logic

## Publish with GitHub Pages
1. Upload all three files to the same root folder of your GitHub repository.
2. Keep the exact filenames and capitalization.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
4. Open the published Pages URL after deployment completes.

## Quiz
The EUEE practice section includes five multiple-choice questions, each with four options (A–D), instant feedback, explanations, score tracking, and a Try again button.

## Scientific model limitations
These are idealized teaching simulations. Projectile motion neglects air resistance; the thin lens is ideal; and the optics interface is flat. Check equations and translations against your curriculum before formal competition submission.
